# PROYECTO 1 #(CONVERTIDOR DE EXPRESIONES)

APLICATVO DISEÑADO PARA CONVERTIR EXPRESIONES MATEMÁTICAS DE NOTACIONES INFIJAS A POSTFIJAS; CONSTRUYE UN ARBOL DE EXPRESION Y REALIZA DIFERENTES RECORRIDOS.
ADemás, EVALUA LA EXPRESION POSTFIJA UTILIZANDO UNA PILA.

# INTRODUCCION

NUESTRO PROYECTO TIENE COMO FINALIDAD FACILITAR LA COMPRENSIÓN DE CÓMO SE PROCESAN LAS EXPRESIONES MATEMATICAS MEDIANTE DIFERENTES PROCESOS, PRESENTÁNDOLAS DE UNA MANERA EDUCATIVA Y VISUALMENTE ATRACTIVA. PARA LOGRAR ESTO, UTILIZAMOS UN ÁRBOL BINARIO PARA REPRESENTAR LA ESTRUCTURA, LO QUE SENCILLA SIGNIFICATIVAMENTE LA VISUALIZACIÓN Y EL ENTENDIMIENTO DEL PROCESO, COMO SE DETALLA EN EL SIGUIENTE APARTADO.

  # FUNCIONES

CONVERSION INFIJA A POSTFIJA
CONSTRUCCION DE ARBOL BINARIO
RECORRIDOS DEL ARBOL
EVALUACION DE EXPRESIONES POSTFIJAS
VALIDACION DE CARACTERES

  # INSTALACION Y USO

1. CLONAR EL REPOSITORIO
2. IMPORTAR EL PROYECTO
  - ABRIR UNA IDE COMPATIBLE (ECLIPSE, NETBEANS, ETC...).
  - IMPORTAR EL PROYECTO CLONADO.
3. EJECUTAR LA APLICACION
  
  - BUSCAR LA CLASE `Proyect1.java`. (`Proyect1.java` ES NUESTRA CLASE PRINCIPAL)
  - EJECUTAR LA CLASE `Proyect1.java` .

AL EJECUTARSE, SE MOSTRARA UN CUADRO DONDE SE PUEDE INGRESAR UNA EXPRESION MATEMATICA. POR EJEMPLO: `( 3 + 5 * 4 - 8 / 2)`. 
LA APLICACION MOSTRARA LA EXPRESION POSTFIJA, LOS RECORRIDOS DEL ARBOL Y EL RESULTADO NUMERICO. 
ADemás SE IMPLEMENTO AL CODIGO UN SEGMENTO QUE PROPORCIONARA EL ARBOL DE FORMA GRAFICA JUNTAMENTE CON EL
COMPORTAMIENTO DE LA PILA AL RESOLVER LA EXPRESION



  ## ESTRUCTURA

CLASES PRINCIPALES:

- **Proyect1.java**: (NUESTRA CLASE PRINCIPAL)
